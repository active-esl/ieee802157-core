CITATION.cff supplies GitHub-readable citation metadata. codemeta.json supplies
CodeMeta2.0 JSON-LD software metadata. CMake project version/description/homepage
matches the intended repository. These files declare the destination, not proof
that a remote repository, topics, security-reporting setting or release exists.

Only public source, synthetic fixtures, build/CI definitions and sanitized
engineering documentation belong in the publication set. Local integration
checkpoint, evidence/, .test-output/, build directories, licensed PDFs, grants,
private board footage and backups are excluded. Review the actual untracked/
tracked file inventory before staging; ignore rules alone are not a secret audit.

Git creation/staging/commit/push, GitHub metadata updates and hosted workflow
execution require their own verified coverage. Local preparation does not prove
remote settings, a successful hosted CI run or standards interoperability.
